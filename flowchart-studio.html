Account & data

Connect a backend

Accounts need a server. Create a free project at supabase.com, then paste its Project URL and anon public key here. The anon key is meant to be public — row level security is what protects the data.

  1. In Google Cloud Console create an OAuth client ID of type Web application, and set its authorised redirect URI to https://<project>.supabase.co/auth/v1/callback. Ask only for the email and profile scopes.
  2. In Supabase, Authentication → Providers → Google: switch it on and paste the client ID and secret.
  3. In Authentication → URL Configuration, add the address this page is published at to the Site URL and the redirect allow list.
  4. Run the SQL below once in the SQL editor.
Run this once in the Supabase SQL editor 
create table public.diagrams (
  id text primary key,
  user_id uuid not null references auth.users on delete cascade,
  name text, src text, folder text,
  created bigint, updated bigint, trashed int default 0
);
alter table public.diagrams enable row level security;
create policy "own rows" on public.diagrams
  for all using (auth.uid() = user_id)
  with check (auth.uid() = user_id);
